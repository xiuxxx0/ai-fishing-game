# AI Fishing Game 🎮

一个基于浏览器的 AI 捕鱼游戏，包含智能队友系统和玩家行为分析功能。

A browser-based AI fishing game with an intelligent companion system and player behavior analysis.

---

## 🎮 Features / 功能

### 中文

- 🤖 **AI队友系统**
  - 智能陪玩，根据玩家行为调整策略
  - 自动攻击鱼类，辅助玩家完成游戏

- 📊 **玩家行为分析**
  - 分析玩家操作习惯
  - 根据游戏表现调整AI行为

- 😊 **情绪与记忆系统**
  - AI拥有简单的情绪反馈机制
  - 根据游戏过程产生不同互动

- 💬 **社交互动系统**
  - AI角色拥有聊天互动能力
  - 增强游戏沉浸感


### English

- 🤖 **AI Companion System**
  - Adaptive AI teammate that adjusts strategies based on player behavior
  - Automatically assists players during gameplay

- 📊 **Player Behavior Analysis**
  - Analyzes player actions and play style
  - Adjusts AI behavior according to game performance

- 😊 **Emotion and Memory System**
  - AI characters have basic emotional responses
  - Creates dynamic interactions during gameplay

- 💬 **Social Interaction System**
  - AI characters can interact with players
  - Improves immersion and game experience
